# AL_AR
# AR Cube - Android AR Application

## 📱 Описание проекта

AR Cube - это Android-приложение, которое использует ARCore для отображения 3D-куба в дополненной реальности после сканирования QR-кода. Приложение сочетает технологии компьютерного зрения (QR-сканирование) и дополненной реальности.

## 🌟 Основные функции

- Сканирование QR-кодов с помощью камеры устройства
- Отображение 3D-куба в AR-пространстве в месте сканирования QR-кода
- Реалистичное позиционирование AR-объекта с учетом окружающей среды
- Интерактивный интерфейс с визуальными подсказками

## 🛠 Технологии

- **ARCore** - платформа дополненной реальности от Google
- **OpenGL ES 3.0** - для рендеринга 3D-графики
- **ZXing** - библиотека для сканирования QR-кодов
- **Android SDK** - нативная разработка под Android

## 📋 Требования

- Android устройство с поддержкой ARCore (список совместимых устройств: [ARCore supported devices](https://developers.google.com/ar/discover/supported-devices))
- Android 8.0 (API 26) или выше
- Камера с автофокусом
- Установленный ARCore (приложение предложит установить при первом запуске)

## 🚀 Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Swanpy/AL_AR.git
   ```
2. Откройте проект в Android Studio
3. Подключите Android-устройство или запустите эмулятор с поддержкой AR
4. Нажмите "Run" в Android Studio

## 🎮 Использование

1. Запустите приложение
2. Разрешите доступ к камере при запросе
3. Наведите камеру на QR-код
4. После успешного сканирования появится 3D-куб
5. Перемещайте устройство - куб будет оставаться на месте сканирования
